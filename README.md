# String class (C++)

College lab: a custom string class (`Stroka_strochenka`) wrapping
`std::string` with extra operations:

- print helpers and a symbol counter
- `deleteSpaces()` — strip spaces from the string
- `reversWords()` — reverse the word order

Everything lives in `Lab-Strings/Lab-Strings.cpp` (Visual Studio solution
`Lab-Strings.sln`).
